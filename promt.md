You are a Senior Full Stack Laravel 12 Developer and UI/UX Designer.

Build a modern, premium, fully dynamic Portfolio Website Builder using Laravel 12, PHP 8.3+, MySQL, Bootstrap 5, JavaScript, AJAX, and Blade Template.

The system should work like a Portfolio CMS where one admin can create unlimited portfolio websites with different professional layouts.

==========================
PROJECT GOAL
==========================

Develop a Professional Portfolio Website Builder where users can create portfolios for different professions without changing code.

Everything must be controlled from the Admin Panel.

The frontend layout will automatically change based on the selected profession/template.
